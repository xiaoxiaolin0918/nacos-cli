# nacos-cli wiki

## Home

Go 主线入口：仓库根目录 `README.md` / `AGENTS.md`。

| 主题 | 说明 |
|------|------|
| 构建 | `go test ./...` / `go build -o nacos.exe .` |
| 写门禁 | `--dry-run` 或 `--yes`（exit 10） |
| 鉴权 | `auth login` / `--web`；token 存本机 credentials.json |
| 归档 | Python v0 → `archive/python-v0` |

示例主机用 `http://127.0.0.1:8848`，勿在公开文档写实验室 IP。
